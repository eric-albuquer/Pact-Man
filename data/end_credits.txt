ALGORÍTMOS E ESTRUTURAS DE DADOS

Tabelas Hash
Hash Table (Open Addressing) - Usada para Chunks
Hash Table (Chaining) - Antigo sistema de Chunks
Perfect Hashing (Minimal Perfect Hashing) - Para propriedades de Cells e Chunks

Árvores e Estruturas Hierárquicas
Prefix Tree (Trie) - Usado para Cheats
Tree Node Pointer - Armazena o input atual de Cheats
Tree Search (DFS) - Usado para liberar Cheats

Grafos e Buscas
Graph Search (BFS) - Utilizado no Path Finder
Queue - Usada no BFS, tentáculos do boss e fogo

Estruturas Espaciais
Local Spatial Matrix - Grade do mapa (Map Grid)
Bitwise Operations - Coordenadas de Cell / Chunk

Ordenação
Sorting Network - Para o Best Path
Quick Sort - Para Score
Merge Sort - Para Score

Listas / Coleções
LinkedList - Enemies por Chunk
Stack - Changed Chunk Enemies
ArrayList - Créditos e banco de dados de Score
Sliding Window - Créditos

Processamento Paralelo
Thread Pool de Carregamento - Processa chunks e entidades próximos ao jogador
Update Multithread - Atualiza inimigos e ambientes em regiões independentes
Sincronização Leve - Minimiza locks usando dados imutáveis e buffers separados
